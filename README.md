# BrewLine Coffee: Power BI Dashboard

Interactive sales dashboard for a fictional 12-store coffee chain.
All data is synthetic, generated for practice.

## Open it
Open BrewLine_Coffee_Sales.pbix in Power BI Desktop. All data is already
loaded, so every slicer and page works without refreshing.

## Refreshing the data (optional)
The report reads the CSVs in the /data folder from the original author's
computer, so Refresh will fail on yours until you repoint them:
1. Home > Transform data > Data source settings
2. Select a CSV source > Change Source > Browse to the matching file in /data
3. Repeat for all 6 files, then Close > Apply changes.
